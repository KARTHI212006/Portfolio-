## Run Locally

### Prerequisites

- Node.js and npm
- Git

### Installation

```bash
git clone https://github.com/KARTHI212006/Portfolio-.git
cd Portfolio-
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

### Production Build

```bash
npm run build
npm run serve
```

The project is configured for static export. The production output is generated in the `out/` directory.

## Project Content

Most portfolio content is maintained in `lib/data.ts`, including profile details, skills, projects, certificates, and education.

Other useful locations:

- `public/resume/KARTHIKEYAN_S_RESUME.pdf` — résumé download asset.
- `public/og.png` — social sharing preview.
- `public/images/` — portfolio and project imagery.

## Accessibility & Motion

- Includes a skip link and visible keyboard focus styles.
- Navigation and dialogs are designed for keyboard interaction.
- Motion respects the visitor's reduced-motion preference.
- Animation effects are implemented with GSAP and cleaned up when components unmount.
