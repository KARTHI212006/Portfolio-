# KARTHIKEYAN S — AI & Software Developer Portfolio

A premium, interactive developer portfolio built for **KARTHIKEYAN S** showcasing software engineering skills, verified projects, industrial internship experience, interactive developer terminal, and career vision.

![Portfolio Preview](assets/images/profile.jpg)

## 🚀 Key Features

- **🖥️ Interactive Developer CLI Terminal:** Real-working JavaScript CLI (`whoami`, `about`, `skills`, `projects`, `experience`, `goal`, `contact`, `clear`) with `Tab` key autocompletion.
- **🔄 Dynamic Hero Role Switching:** Smoothly cycles between *Java Full Stack Developer*, *Prompt Engineer*, *AI & Web Developer*, and *Software Engineer*.
- **🧩 Interactive Project Filtering & Modals:** Dynamic filter tabs (*ALL*, *WEB*, *JAVA*, *AI / IOT*) with smooth CSS scale/opacity transitions and detailed project breakdown modals (Problem, Solution, Features, Tech Stack, Contribution).
- **🧠 Interactive Skills Ecosystem:** Categorized technical skill filter (*ALL*, *PROGRAMMING*, *WEB*, *DATABASE*, *TOOLS*, *AI*).
- **💼 Verified Experience & Certifications:** Highlights the 34-day industrial IoT internship at **ZEN 1 TECHPARK, Coimbatore** with interactive full-screen certificate modal viewer.
- **🎯 Career Vision Spotlight:** Visual section highlighting the long-term career goal: **AI Engineer at Google**.
- **⚡ Zero Framework Overhead:** Built using 100% pure HTML5, CSS3, and ES6+ Vanilla JavaScript. Zero React, zero heavy libraries (GSAP, Three.js, WebGL), ensuring sub-second load times and high performance.
